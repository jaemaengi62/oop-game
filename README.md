# OOP Game

## 핵심적으로 배운 개념

### 1. is-a와 has-a를 코드로 표현하는 방법

처음에는 has-a 관계를 어떻게 구현하는지 몰라 `Dragon = Monster()`처럼 작성했습니다. 실습을 통해 두 관계를 표현하는 방법을 배웠습니다.

- **is-a**: `class Dragon(Monster):`처럼 상속으로 표현합니다. 드래곤은 몬스터의 한 종류입니다.
- **has-a**: `self.hp = HP(150)`처럼 다른 객체를 속성으로 가집니다. 캐릭터는 체력 객체를 가집니다.
- `Dragon = Monster()` 자체는 객체를 만들어 변수에 저장하는 코드이며, 이것만으로 객체 사이의 has-a 관계가 만들어지지는 않습니다.

상속 관계에서는 `super()`를 통해 부모 클래스의 초기화 코드를 재사용하는 방법도 배웠습니다.

### 2. 객체를 생성하고 전달하는 방법

숫자, 문자열, 객체 중 무엇을 전달하는지 구분해야 한다는 것을 배웠습니다.

- `HP(150)`을 다시 `HP()`로 감싸서 체력 숫자 대신 객체가 저장되었고, 뺄셈에서 오류가 발생했습니다.
- 인벤토리에서 `Weapon(name=item)`으로 아이템을 다시 감싸 이름에 객체가 들어가고 공격력과 속성을 잃었습니다.
- 이미 만들어진 객체를 전달받았을 때는 다시 생성하지 않고 그대로 저장하도록 수정했습니다.

### 3. 상태 변경과 반환값의 차이

메서드 안에서 작업했다고 결과가 자동으로 반환되는 것은 아니라는 것을 배웠습니다.

- 로그를 만들고도 반환하지 않아 `NoneType` 반복 오류가 발생했습니다.
- 아이템을 인벤토리에서 삭제하고도 반환하지 않아 장착과 강화가 실패했습니다.
- 호출한 곳에서 결과를 사용할 수 있도록 각각 `return log`, `return item`을 추가했습니다.

### 4. 한 번의 동작과 전체 흐름을 나누는 방법

`attack()` 안에서 죽을 때까지 반복 공격해 보스가 1턴 만에 쓰러졌습니다. 한 번의 공격은 메서드에서 처리하고, 턴 반복은 바깥에서 처리하도록 나눴습니다.

## 구현하면서 고친 실수

| 문제 | 해결 |
| --- | --- |
| `Weapon("물의 창", 25, "물")`에서 속성과 공격력의 인수 순서가 뒤바뀜 | 키워드 인수로 각 값의 의미를 명확히 전달 |
| 새 경험치만 비교해 60과 90을 얻어도 레벨 업이 누락됨 | 기존 경험치에 누적한 뒤 레벨 업마다 필요 경험치를 차감 |
| 로그에 레벨 숫자 대신 `Level` 객체를 넣음 | `self.level.level`로 숫자를 출력 |
| 강화하지 않은 무기 이름 앞에도 공백이 붙음 | `__str__()`에서 강화 여부에 따라 접두사를 구성 |

## 프로젝트 소개

파이썬 객체지향 프로그래밍을 연습하는 콘솔 전투 시뮬레이션입니다. 전사 아서가 슬라임과 골렘을 처치하고, 획득한 무기를 장착·강화한 뒤 보스와 싸웁니다.

## 실행 방법

Git과 Python 3.6 이상이 필요하며, 스크립트 실행에는 외부 파이썬 패키지가 필요하지 않습니다.

```bash
git clone https://github.com/jaemaengi62/oop-game.git
cd oop-game
python game.py
```

사용자 입력 없이 정해진 시나리오가 실행됩니다. `game.ipynb`는 Jupyter 또는 VS Code의 노트북 환경에서 열 수 있습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `game.py` | 클래스 정의와 전투 시나리오 |
| `game.ipynb` | 노트북 형식의 실습 파일 |

## 주요 기능

- 체력 관리: 피해 처리, 생존 여부 확인, 최대 체력 회복
- 속성 상성: 불 → 풀 → 물 → 불 순서로 유리하며, 피해 배율은 유리할 때 2배, 같을 때 1배, 나머지는 0.5배
- 경험치와 레벨: 필요 경험치는 현재 레벨 × 100, 레벨 업마다 최대 체력 20 증가 및 전부 회복
- 인벤토리: 기본 용량 5개, 아이템 획득과 이름으로 꺼내기
- 무기 교체와 강화: 기존 무기를 인벤토리에 보관하며, 강화석 하나로 공격력 5 증가
- 턴 단위 공격: `attack()` 한 번에 한 번 공격하고 로그 목록 반환

## 클래스 구조

상속은 **is-a**, 객체를 속성으로 가지는 구성은 **has-a** 관계로 표현합니다.

```text
GameObject
├── Character
│   ├── Warrior
│   └── Wizard
└── Monster
    ├── Slime
    ├── Golem
    └── Dragon

Item
└── Weapon
```

`Character`는 `HP`, `Weapon`, `Level`, `Inventory` 객체를 가지고, `Weapon`은 `Element` 객체를 가집니다.

## 현재 실습 범위

`game.py`의 기본 시나리오는 전사의 일반 공격, 속성 상성, 처치 보상, 아이템 장착·강화, 누적 경험치와 레벨 업을 실행합니다. 보스전은 강화한 물의 창으로 5턴에 끝나며, 최종 상태는 Lv.4, EXP 50입니다.

| 구분 | 현재 코드 상태 |
| --- | --- |
| 전사와 마법사 | 두 클래스 모두 생성할 수 있습니다. 마법사의 지팡이는 공격력 8이며 속성은 기본값인 빈 문자열입니다. 기본 시나리오에서는 전사만 사용합니다. |
| 스킬과 방어구 | `Skill`, `Armor` 클래스와 관련 메서드는 있지만, 캐릭터에 `skill`, `armor` 속성을 설정하지 않아 `use_skill()`과 `take_damage()`를 바로 호출하면 `AttributeError`가 발생합니다. |
| 이동과 좌표 | `GameObject`에 `move()`, `info()`가 있습니다. 캐릭터는 좌표가 초기화되지만, 몬스터는 부모 생성자를 호출하지 않아 해당 메서드를 사용하려면 좌표 초기화가 필요합니다. |
| 전투 방식 | 캐릭터가 몬스터를 공격하는 방식이며, 몬스터의 반격과 사용자 입력은 구현되어 있지 않습니다. |
| 파일 실행 | 파일 하단에서 시나리오를 바로 실행하므로, 다른 파일에서 `import game`을 해도 전투 로그가 출력됩니다. |
